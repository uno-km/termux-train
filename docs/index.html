Termux-Train

Ultra-Lightweight On-Device Tensor & DAG Autograd Deep Learning Framework

1-Line Quick Installation

Install the official package directly into your runtime:

pip install termux-train

The Engineering Challenge

Training or fine-tuning neural networks on mobile devices with standard deep learning toolchains causes Out-Of-Memory (OOM) crashes and excessive disk paging.

The Architectural Breakthrough

Implements a pure C++/Python dynamic computation DAG with SafeTensors zero-copy serialization and memory-mapped LoRA backpropagation on ARM64.

Key Capabilities & Built-in Hardening

Zero-Copy SafeTensors Serialization

Loads and saves model checkpoints with zero memory duplication via mmap.

Dynamic DAG Autograd Engine

Closed-form gradient computation with minimal heap allocation during backward pass.

On-Device LoRA Fine-Tuning

Optimized low-rank adaptation matrix training directly on mobile CPU/NEON cores.

Supported Compute Kernels & Operations

Subsystem Category Operations & Kernels Status
Tensor Operations Dynamic DAG Autograd, SafeTensors IO, RoPE Positional Encoding Production
Optimizers AdamW, SGD with Momentum, Cosine Annealing LR Scheduler Production
Target Hardware ARM64 Bionic libc, NEON SIMD, Multi-Core OpenMP Production

Canonical Usage Example

import termux_train as tt

# 1. Define model with LoRA layers
model = tt.nn.TransformerLoRA(vocab_size=32000, dim=512, lora_rank=8)
optimizer = tt.optim.AdamW(model.parameters(), lr=1e-4)

# 2. Train on-device with zero memory overhead
for epoch in range(5):
    loss = model(inputs, targets)
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()
    print(f"Epoch {epoch}: Loss = {loss.item():.4f}")

// Termux-Train is primarily a Python native ML framework.
// Models can be exported to standard SafeTensors format for universal deployment.
