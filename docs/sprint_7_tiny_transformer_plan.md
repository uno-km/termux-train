# Sprint 7: Tiny Transformer End-to-End Training Plan

> **Objective:** Train an autoregressive language model directly within Termux.

---

## Model Specifications
- Vocabulary Size: 4,096
- Embedding Dimension: 128
- Attention Heads: 4
- Layers: 2
- Context Length: 256 tokens
- Optimizer: AdamW (LR: 1e-3, Weight Decay: 0.01)
