# Granular Scoring Protocol (0-Point Baseline)

## Core Principles
1. **0-Point Baseline**: Start at 0 points; accumulate score strictly upon verified test assertions.
2. **Deterministic Evaluation**: Evaluate latency, memory safety, error rates, and numerical precision independently.
3. **No False Pass**: Mocked objects or non-functional placeholders receive 0 points.
