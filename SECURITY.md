# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, buffer overflow, or memory safety defect within `termux-train`, please report it privately:

1. **Email**: `zhfldk014745@naver.com`
2. **Security Advisories**: Open a private draft advisory via GitHub Security Advisories.

Please do not report security vulnerabilities through public GitHub issues. All security reports will receive a response within 48 hours.
